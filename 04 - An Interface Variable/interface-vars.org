#+TITLE: Interface variables

* Loading data
#+BEGIN_SRC spirv
%id = OpLoad %type %ptr
#+END_SRC

Loads the value from %ptr of %type into %id

* Using interface variables
A SPIR-V entry point has an associated interface. Suppose we defined a main function and didn't define its interface:

#+BEGIN_SRC spirv
OpEntryPoint Vertex %3 "main"
#+END_SRC

Trying to access any global variables from within that function would result in the following ~spirv-val~ validation error:

#+BEGIN_SRC
error: line 8: Interface variable id <7> is used by entry point 'main' id <3>, but is not listed as an interface
#+END_SRC

We have to list each accessed variable as ~OpEntryPoint~ parameters:

#+BEGIN_SRC spirv
OpEntryPoint Vertex %3 "main" %7
#+END_SRC
